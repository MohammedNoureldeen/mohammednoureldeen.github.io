Transcript correction

How do you fix a glossary term without moving a word in time?

Fictional Example

Compare both occurrences of “spoken.” Switch states and watch which word changes and which times stay fixed.

CUSTOM GLOSSARY ENTRY: "Spokn" (Product noun — do not alter ordinary verb "spoken")

“We recorded our team update on Spokn [00:04.12 – 00:04.58] right after we had spoken [00:06.80 – 00:07.24] with engineering.”

State — Context-Aware Glossary Patch: Occurrence 1 updates from "spoken" → "Spokn" (product noun), Occurrence 2 stays "spoken" (ordinary verb), and both word timecodes (00:04.12–00:04.58 and 00:06.80–00:07.24) remain 100% unchanged.

What I built

At Spokn I integrated OpenAI into glossary-based transcript correction. The correction considers the context of each occurrence. A corrected word keeps its original start and end times so it still points to the same piece of audio. When a model call fails, the pipeline retains the original text.

Mohamed’s Engineering Note · Designing AI features for failure

“An AI polish step should never be a single point of failure for a core media workflow. Locking timestamps in code and keeping the original transcript when a model call fails keeps editing predictable.”
